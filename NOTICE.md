# Third-party attribution

## Blinkie badge artwork

`assets/blinkies/*.png` and `landing/public/blinkies/*.png` are pixel-art
badge backgrounds taken from **blinkies.cafe** by piconaut:

- Source: https://github.com/piconaut/blinkies.cafe
- License: GNU General Public License v3.0 (GPL-3.0) — see `/LICENSE`

These files are used unmodified as background images, composited at runtime
with this app's own text (Press Start 2P) and its own catalog of labels —
see `src/constants/blinkies.ts` / `landing/src/constants/blinkies.ts`. Two
of the source repo's background designs (`0022-iheart-0.png`,
`0026-iheart2-0.png`) were deliberately excluded because they have fixed
text baked into the artwork itself, which would collide with this app's own
custom text.

Because this project incorporates GPL-3.0-licensed material, the project as
a whole is licensed under GPL-3.0-or-later — see `/LICENSE`.
